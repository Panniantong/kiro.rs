Kiro Admin 批量操作设计

决策：反选作用于当前可见视图；批量备注直接覆盖；批量弹窗允许只改备注、只改优先级或同时修改。

交互

  • 选中凭据后，工具栏新增“反选”和“批量编辑”。
  • 卡片视图反选当前页；可用紧凑反选当前全部可用；全部紧凑反选全部可见凭据。
  • 批量编辑弹窗显示选中数量，备注和优先级均可留空；至少填写一项才能保存。
  • 备注非空时覆盖选中账号的 importNote；优先级必须为非负整数。

后端

新增 POST /credentials/batch-update，请求字段：ids、可选 importNote、可选 priority。服务端在一次锁和一次 persist 中更新所有账号；找不到任何 ID 时快速失败。

验证

  • 后端测试：备注覆盖、优先级批量更新、部分不存在 ID、空更新拒绝。
  • 前端构建通过；浏览器验证当前视图反选和批量弹窗。
  • 8992 灰度后再部署 8993；两个端口 Admin API 与 /v1/models 均为 200。
