Kiro Admin：全局 RPM 与高密度凭据视图

设计日期：2026-08-27；基线：生产 commit 7ee72de；目标端口：8992 / 8993。

采用方案：保留现有卡片操作视图，同时新增“可用紧凑”和“全部紧凑”两种高密度表格视图；全部使用现有 Admin API 字段，不新增后端数据模型。

1. 顶部全局 RPM

统计区从 3 张卡扩为 4 张：凭据总数、可用凭据、全局 RPM、当前活跃。

  • 主数字：所有启用凭据 currentRpm 之和，表示最近 60 秒上游尝试总数。
  • 副文案：所有启用凭据 peakRpm1h 之和，并显示近 1h 本地 throttled 总数。
  • 不把配置值 defaultRpm=99999 当作实际 RPM。

2. 默认排序

  1. 启用凭据优先。
  2. 当前活跃凭据优先。
  3. priority 数字升序。
  4. id 升序，保证稳定。

排序只影响展示，不改变路由和凭据优先级。

3. 三档视图

模式数据布局分页
卡片全部凭据现有 3 列卡片，保留全部操作12 条/页
可用紧凑仅启用凭据高密度表格单页展示全部可用凭据
全部紧凑全部凭据高密度表格单页展示全部凭据

视图选择保存在 localStorage，刷新后保留。切换视图重置选择与页码。

4. 紧凑表格字段

每行显示：选择框、ID/邮箱、启用/禁用及原因、认证方式、订阅等级、实时 RPM/有效上限/近1h峰值、剩余额度/总额、分组/备注（importNote）、优先级、最后调用、启用开关。

余额来自现有 GET /credentials/{id}/balance。进入紧凑视图后按可见凭据自动补齐 balanceMap；有缓存直接显示，加载中显示占位，不阻塞列表。

  • 从当前生产 HEAD 7ee72de 创建 fluxnode/admin-rpm-views-20260827。
